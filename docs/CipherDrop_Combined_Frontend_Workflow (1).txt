==================================================
6. PHASE 4 — SHARE URL
==================================================

Backend returns:

{
    id: "abc123"
}

The frontend constructs:

/s/abc123#AES_KEY

The URL contains:

/s/abc123
    -> Secret ID

#AES_KEY
    -> AES decryption key

The secret ID is used to communicate with the backend.

The AES key is kept in the URL fragment and is used by the browser for decryption.

Coordinate so key handling is implemented cleanly rather than having multiple parts of the UI manipulate the key independently.
